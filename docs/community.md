# 菜单、群娱与社区管理

这套服务按[超级の群娱公开教程](https://cjqy.isoox.cn/page/course.html)和[指令说明](https://cjqy.isoox.cn/page/instruct.html)中描述的使用方式原生实现。没有加载其 DLL，也不包含插件代码、图片、旧基础数据或付费扩展。原插件的菜单由自定义回复构成；罐头喵使用可定制的文本菜单，并自动按权限、场景和功能开关筛选内容。

群娱不依赖模型、API Key 或外部游戏接口。`community.enabled` 缺省开启；关闭这一节会同时停用社区菜单、游戏、名单策略和社区管理，原有 AI、文件等服务仍按其自身配置运行。

## 开始使用

新群默认关闭。主人、社区超管、本群后台管理或 QQ 群主可在群中发送 `开启本群`（兼容 `/bot on`），然后发送 `功能` 或 `菜单`。开启 bot 不会自动开启 AI，群 AI 只能由配置中的主人在目标群单独开启，其他管理员、社区超管和 QQ 群主均不能代开。

## 群 AI 独立设置

主人先在私聊使用 `/provider` 配置模型提供商、`/model` 选择模型，再到已开启 bot 的目标群设置：

```text
/ai settings
/ai mention on
/ai probability 0
/ai on
/ai off
/ai reset
```

`/ai`、`/ai status`、`/ai settings` 只查看状态，不会隐式开启。仅主人能修改开关与触发设置，私聊中不能修改目标群 AI，也不使用社区的“当前管理群”选择。`/ai on` 要求已配置默认提供商和模型；未配置时保留关闭状态。

`mention on` 只响应 @bot；`mention off` 时 @bot 仍必响应，普通消息由本群 `probability`（0到1）决定。未覆盖的值继承 `config.yaml` 中 `ai.mention_only` 与 `ai.reply_probability`；`reset` 清除本群触发覆盖值，保留 AI 开关。设置持久化、按群隔离，修改写入 `perm.db` 中的 `group_ai_audit`。

群 AI 默认关闭；旧 `ai_enabled` 记录因无法证明由主人授权，不会在升级后自动生效，需要主人重新 `/ai on`。主人身份变更后旧主人的授权失效。AI 关闭时不调用群模型、不进行 AI 情绪识别、主动插话或输出模型配置引导；私聊 AI 与群娱继续独立工作。主人 `/ai off` 不会被正在等待模型或审批的群会话锁阻塞，已等待批准的 AI 工具在执行前再次检查开关。

私聊可直接使用 `功能`、`签到`、`查询` 等个人娱乐指令。私聊管理群时先发送 `群列表`，再发送 `选择管理群 <群号>`，后续管理命令针对选定群，每次重新检查权限。`当前管理群` 可确认目标。群列表只读展示前100个群中有管理权限的群，每人每分钟最多查询一次。

关闭群中全员静默，仅保留开启、关闭本群命令；私聊仍可管理已选择的群。

## 权限与审批

| 数值 | 身份 | 来源与范围 |
| --- | --- | --- |
| 0 | 普通成员 | 默认身份 |
| 20 | QQ 群管理 | 从 OneBot 实时查询，限本群 |
| 30 | 后台管理 | `添加后台管理 <QQ>`，限本群；兼容原本群 admin 记录 |
| 40 | QQ 群主 | 从 OneBot 实时查询，限本群 |
| 50 | 社区超管 | 主人用 `添加超管 <QQ>` 授予；配置管理员也具有此社区级别 |
| 60 | 主人 | 仅 `bot.master_id` 对应的真实发送者 |

`我的权限` 显示当前场景的权限值。QQ 角色查询失败不会产生额外授权。私聊选择管理群要求至少30级，并确认 bot 仍是该群成员；非全局管理员还必须继续是目标群成员。

- 20级可发起群管操作、管理警告。
- 30级可管理本群开关、菜单、回复、关键词、名单与事件模板。
- 40级可切换数据模式，授予或撤销更低级的本群后台管理。
- 只有主人可授予社区超管、管理全局规则、调整虚拟金币、屏蔽私聊和控制私聊转发。
- 社区超管不会因此获得系统命令、ACP 或其他 AI 高风险工具的审批权。

安全审核仅适用于 Agent 调用工具执行的操作。管理员直接发送禁言、解禁、移出、名片、群名、全体禁言、群公告、撤回等固定命令，权限校验通过后直接执行，无需二次批准；私聊管理选定群遵循相同规则。管理员配置的关键词处罚按规则自动执行。`退出群聊`、设置或取消 QQ 群管理仍仅主人可直接操作；bot 也须满足 QQ 协议要求的角色。

管理员通过自然语言要求 Agent 执行操作时，仍进入 AI 工具的风险分级审批；即使发起人本身是主人或管理员，也不会因此跳过审核。高风险批准者是配置中的主人或 `bot.admin_ids` 管理员；QQ 群主、后台管理和社区超管不会因此获得 AI 高风险审批权。

直接命令执行前仍检查真实请求者权限、目标保护、bot 群身份、参数和开关，操作取消、关闭群或撤销权限后不执行。主人、全局管理员、QQ 管理及后台管理受到目标保护；模板不能绕过这些检查。群管操作最多同时执行8条，并保存执行审计记录。

## 菜单和回复

菜单入口包括 `功能`、`娱乐功能`、`农场功能`、`坐骑功能`、`钓鱼系统`、`排行功能`、`群管功能`、`管理功能`、`私聊功能`、`主人功能`。

```text
设置菜单 all 欢迎来到本群$换行$$菜单$
删除菜单 all
菜单设置
添加回复 精准 群聊 0 晚安|晚安，$QQ$！
添加回复 模糊 全部 0 早上好|早上好$换行$现在是$时间$
删除回复 晚安
回复列表
```

菜单类别可用 `all`、娱乐、排行、农场、坐骑、钓鱼、群管、管理、私聊、主人。模板最多1000字，必须包含一次 `$菜单$`，由程序插入筛选后的实际功能。删除本群模板后恢复全局模板或默认菜单。

回复支持精准/模糊匹配，群聊/私聊/全部场景及最低数字权限。同一个关键词，本群覆盖全局；精准优先于模糊，其次较长关键词优先，再按关键词排序。每个范围最多100条，每条正文最多2000字。管理内置指令与 `/` 命令优先，不能通过自定义回复覆盖。

模板支持 `$QQ$`、`$昵称$`（当前以用户编号显示）、`$群号$`、`$操作者$`、`$时间$`、`$换行$`。模板输出为纯文本，不解释 CQ、文件路径、HTTP 请求、脚本、禁言或其他动作文本代码。

主人可用 `设置全局菜单`、`删除全局菜单`、`全局菜单设置`、`添加全局回复`、`删除全局回复`、`全局回复列表` 管理默认规则。仅全局回复会在普通私聊中匹配，本群回复不会泄露到私聊。

## 娱乐功能

| 功能 | 指令与规则 |
| --- | --- |
| 签到 | `签到`、`查询`；每天一次，100–200金币与10–20经验，记录累计/连续签到，主人也不能重复领 |
| 运势 | `今日人品`、`抽签`；同用户、数据范围、日期内结果固定，仅供娱乐 |
| 骰子 | `.rd`、`.r3d6`、`.2r5d20+3`、`.rd+5-6+12`；默认100面，最多10轮、共100颗，面数2–1000 |
| 赠送 | `赠送 <QQ> <数量>`，或 `赠送 @成员 <数量>`；仅同群其他成员，最低100；手续费按配置扣除 |
| 银行 | `存款 <数量>`、`取款 <数量>`、`我的存款`；无利息、无真实货币 |
| 排行 | 金币/货币、经验、银行、签到、连续签到、钓鱼、今日/本月/累计发言排行；当前范围前10名 |
| 发言 | `我的发言`；去重后统计，每30秒最多奖励2金币，每日最多30次，不统计管理命令与被关键词拦截的消息 |
| 农场 | `我的农场`、`种子商店`、`开耕 2`、`种植 1 小麦`、`全部种植 土豆`、`农场收割 1`、`农场全部收割`；兼容 `种植1-小麦` 等紧凑写法 |
| 坐骑 | `坐骑商店`、`购买坐骑 <名称>`、`我的坐骑`、`当前坐骑`、`设置坐骑 <名称>`、`取消坐骑`、`查看坐骑 <名称>`；装备后增加签到奖励 |
| 钓鱼 | `鱼竿商店`、`购买鱼竿 <名称>`、`我的鱼竿`、`钓鱼`、`提竿`；抛竿消耗耐久，30–90秒后咬钩，随后2分钟内提竿 |

农场首格免费，最多9格，其余每格开耕500金币。自有作物为小麦、土豆和南瓜，成熟时间分别5分钟、20分钟和1小时。坐骑和鱼竿商店使用自有名称与数值，没有复制原插件的资源目录。农场成熟时间、鱼竿耐久与钓鱼窗口都持久化，重启后继续按实际时间结算。

娱乐数据通过 SQLite 事务提交。并发转账不会产生负余额或重复扣款，失败时整笔回滚；单项余额和经验上限为一万亿。主人可对选定管理群的数据范围使用 `发放金币 <QQ> <数量>`、`扣除金币 <QQ> <数量>`，操作写审计。

## 分群、开关和名单

`数据模式 separate` 使用本群账户，`数据模式 global` 在采用全局模式的群之间共享同一用户账户。**两套数据一直保留，切换不会迁移或覆盖**。模式只影响游戏、银行与排行；群权限、开关、名单、回复和事件仍按群隔离。私聊账户始终按用户隔离，即使私聊已选择管理群也不混入群娱乐数据。

`功能开关` 查看状态，`开启功能 <功能名>`、`关闭功能 <功能名>` 调整本群覆盖值。可用功能名：签到、运势、骰子、转账、银行、排行、发言、农场、坐骑、钓鱼、回复、关键词、事件、群管。主人使用 `全局功能开关`、`开启全局功能`、`关闭全局功能` 调整默认值；本群已有覆盖值时优先使用本群设置。

```text
添加名单 black <QQ>
添加名单 white <QQ>
添加名单 gray <QQ>
删除名单 black <QQ>
查看名单 black
```

黑名单、灰名单均停止处理该用户的消息，白名单仅豁免关键词过滤，**不升级权限**。全局黑/灰与本群黑/灰均生效，白名单不会覆盖它们。不能屏蔽同级或更高权限，主人保留解除错误配置的能力。主人通过 `添加全局名单`、`删除全局名单`、`查看全局名单` 管理全局范围。名单策略位于所有服务及快捷审批处理之前，适用于 AI、文件和插件消息入口。

## 群聊管理

```text
禁言 <QQ> <时长>
解禁 <QQ>
移出 <QQ>
群名片 <QQ> <内容>
群名 <内容>
全体禁言
全体解禁
群公告 <内容>
撤回
警告 <QQ>
查警告 <QQ>
清空警告 <QQ>
群审计
```

撤回需在原群引用目标消息；会查询消息实际群号与发送者，不能跨群猜测消息编号。警告仅记录本群计数，不会自动变成禁言或踢人。`我的警告` 可查询本人。QQ群接口返回失败或超时记为失败/结果不确定，不自动重放。`群审计` 展示最近20条本群管理记录；主人用 `全局审计` 查全局规则、转账、游戏和余额调整记录。

禁言时长兼容纯数字（分钟）及 `10分钟`、`30秒`、`2小时`、`1天`、`10m`、`30s`、`2h`、`1d`，范围1秒至30天。不支持混合单位或小数；格式错误只显示用法提示，不暴露程序解析错误。所有形式均需相同的身份与权限校验，管理员直接下达命令无需安全审核。

关键词规则只处理群消息，普通成员触发，QQ 管理及更高权限默认豁免：

```text
添加关键词 reply 欢迎|欢迎来到本群
添加关键词 warn 不当词|
添加关键词 ban 不当词|5
添加关键词 kick 严重违规词|
添加关键词 recall 不当词|
添加关键词 black 严重违规词|
删除关键词 不当词
关键词列表
```

处罚目标固定为真实事件发送者。`ban` 正文为1至43200分钟；`reply` 是纯文本回复，`warn` 记录警告。禁言、移出、撤回、拉黑按管理员设置的规则直接执行，每位用户每分钟至多触发一次处罚；执行前验证目标保护、白名单和规则是否仍有效。多条关键词按关键词排序，命中第一条后停止。

事件模板支持 `welcome` 入群、`leave` 离群、`admin` QQ管理变动、`card` 名片变动：

```text
设置事件 welcome 欢迎$QQ$加入$群号$
设置事件 leave $QQ$离开了本群
删除事件 welcome
事件列表
```

入群申请沿用原 `group_request` 服务的 `/入群申请`、`/同意 <编号>`、`/拒绝 <编号> [理由]`。好友申请以独立的「好友申请」通知发给主人，由主人私聊回复 `同意 <完整编号>` 或 `拒绝 <完整编号>` 处理，超时不调用处理接口。这是申请处理流程，与 Agent 安全审核独立；确认后直接处理，无额外审核。

## 私聊管理与转发

主人可用 `私聊屏蔽 <QQ>`、`取消私聊屏蔽 <QQ>` 管理私聊入口。`开启私聊转发`、`关闭私聊转发`、`私聊转发状态` 仅主人私聊可用，默认关闭。

开启后只把未被命令、菜单或游戏消费的私聊文本转发给主人，每位用户每分钟最多一条、最多1000字；不转发附件、斜杠命令及包含常见凭据标记的文本。主人和 bot 自身不进入转发链，避免循环。主人可用 `回复私聊 <QQ> <内容>` 回复已经转发过的联系人，不能借此任意群发；回复前再次检查屏蔽状态。

## 配置、存储与范围

```yaml
community:
  enabled: true
  timezone: "Asia/Shanghai"
  default_mode: "separate"
  transfer_fee_bps: 0 # 100 = 1%，配置范围0–1000，缺省0
```

状态位于 `data/community.db`，使用 WAL，与权限库、AI 会话库独立。备份时停止 bot 并使用 SQLite 备份接口，或在停机状态同时保留数据库及 WAL。社区规则修改、账户变更、申请处理与执行结果有持久化审计；发言奖励不逐条写审计。消息去重记录保留7天；已领取但因崩溃未完成的操作不会自动重放。

当前实现覆盖上述原生核心，并非专有插件的完整兼容层。未移植图片菜单渲染、礼物/魅力/邀请系统、活动与卡密、偷菜/放火、炸弹/裁决处罚、原插件所有可配置数值及任意文本代码执行。点歌、Epic/Steam/B站、快递等外部查询尚未接入；卡牌属于独立扩展，好友删除、钱包、框架截图等也未提供。菜单不会展示这些未实现入口。
