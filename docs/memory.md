# 长期记忆

`memory.enabled: true` 启用长期记忆。无需向量服务也能保存事实和进行本地中文检索。若配置有效的 `memory.embed_base_url`、`embed_api_key` 和 `embed_model`，召回会融合向量与关键词；服务失败时保留事实并回退本地检索，单次 embedding 最多等待三秒，失败后一分钟内不重复请求。

## 记什么、如何更新

自动记忆只处理真实发言者当前消息中明确的第一人称事实：姓名、居住地、喜好和学习目标。问句、假设、转述、引用消息、图片转述、AI 回复和普通问候不自动保存。内容限 600 字，匹配到的密码、API Key 等凭据拒绝存储。

同一用户、同一会话中的重复内容不重复写入。姓名、居住地等稳定字段使用事实键更新原记录，保留记忆 ID；偏好以对象为键，“我喜欢咖啡”和“我不喜欢咖啡”更新同一条偏好。

可以直接对 bot 说：

- “记住我喜欢喝无糖咖啡。”
- “我改名字了，以后叫我小林，更新之前的记忆。”
- “列出你在这里记住的关于我的信息。”
- “忘掉那条关于咖啡的记忆。”

Agent 使用 `remember`、`list_memories` 和 `forget_memory`。`remember` 的 key 可以指向已存在的稳定事实；工具只作用于真实发言者在当前会话中的记忆。遗忘会删除选定的长期记忆，不会同步删除对话历史或会话摘要。`/clear` 管理短期对话窗口，不代替长期记忆遗忘。

## 隔离与召回

私聊记忆只在该用户私聊使用，不再自动带入群聊。群记忆按群号和真实用户隔离；`session_mode: merged` 仍记录事实所属的真实用户，其他人发言不会套用这条个人记忆。不同群相互隔离，没有隐式全局共享。

每次仅查询当前范围最近 500 条候选，按中文双字词/单词匹配、同模型向量相似度和更新时间排序。不同 embedding 模型或维度的向量不会混用；没有足够相关性的事实不注入。召回默认最多五条，可用 `recall_limit` 调整（上限 20），注入总长度限制为 1800 字。返回内容包含来源用户和更新时间，并明确标为背景数据，不能授予权限或替代当前指令。

旧版数据库自动补齐事实键、更新时间、来源消息和向量模型字段。原记录保留；旧版 `[对话]` 闲聊片段不再自动召回，无法确定真实用户的合并群旧记录也不会冒充当前用户事实。旧向量缺少模型标识时仅使用关键词检索，不需要删除或重建数据库。

记忆保存在运行时 `data/memory.db`，跟随 `data.dir`，不提交到仓库。升级前备份此文件和现有会话数据库。
